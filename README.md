# Spanish Practice

A beginner Spanish vocabulary app designed for comfortable reading and keyboard navigation.

## Open the app

Download or clone this repository and open `index.html` in a web browser. No installation, build step, or server is required.

## Features

- Left-side **1. Definitions** navigation with 10 common reflexive verbs.
- Switch to show or hide English translations.
- Three text sizes and high-contrast colors.
- Keyboard-accessible controls, visible focus indicators, and screen-reader labels.
- Display preferences saved locally in the browser when available.

## Files

- `index.html`: page structure and vocabulary.
- `styles.css`: layout and visual styling.
- `app.js`: display controls and preference storage.
# Audio practice

Lesson **6. Audio** unlocks with the other advanced lessons after a perfect score on **2. Quiz**. It selects 10 distinct English prompts from **5. Quiz**. Play reads a prompt; Record starts Spanish speech recognition, and Stop recording grades the recognized conjugated verb. Reflexive pronouns are required; valid Spanish variants of the same English prompt are accepted. Each answer earns 0 or 1 point. Incorrect answers play the correct Spanish audio and can be retried; correct answers are complete. The Play button shows a light-green background during playback; clicking it again stops the audio.

Use HTTPS (including GitHub Pages) or localhost and allow microphone access. Speech recognition requires a compatible browser and may require an internet connection and the browser provider’s speech service. The app does not save recordings. Recognition errors leave the score unchanged; this is a word-matching exercise, not a pronunciation assessment.
